# Adaptive Harness Guide

状態: template  
日付: 2026-07-12  
関連: [ドキュメント入口](../README.md)

## 背景

AIエージェントと人間が同じリポジトリで作業する場合、チャット履歴だけでなく、仕様・判断・計画をリポジトリ内の文書として残す必要があります。

## 決定

- 作業ルールは `AGENTS.md` に入口だけを置き、詳細は関連するMarkdownへ分ける。
- 仕様、設計判断、実行計画はそれぞれの索引で管理する。
- Pull Requestでは目的、主な変更点、影響、確認方法を揃える。

## 影響

新しい変更では、関連文書の確認、必要なテンプレートの複製、索引更新、検証結果の記録を同じ変更に含めます。
