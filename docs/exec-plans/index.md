# 実行計画

複雑な変更の計画、進捗、決定、フォローアップを管理します。

## ディレクトリ

- [active/](active/) - 進行中の計画
- [completed/](completed/) - 完了した計画
- [tech-debt-tracker.md](tech-debt-tracker.md) - 技術的負債の一覧

## 作成手順

1. [exec-planテンプレート](../templates/exec-plan.md) を `active/` へコピーする。
2. 作業中に進捗、決定ログ、検証結果を更新する。
3. 完了後は `completed/` へ移動し、この索引を更新する。
